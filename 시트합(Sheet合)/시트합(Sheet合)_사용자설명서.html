시트합(Sheet合) 프로그램 설명서

엑셀 파일 자동 취합 도구

프로그램 소개

'시트합'은 여러 개의 엑셀 파일에 나뉘어 작성된 데이터를 하나의 기준(Base) 파일에 자동으로 취합해주는 오프라인 도구입니다. 수작업으로 하던 복사/붙여넣기 작업을 자동화하여 업무 효율을 높이고 실수를 줄일 수 있습니다.

주요 특징

완벽한 오프라인 작동

모든 파일 처리는 사용자 PC에서 직접 이루어집니다. 외부 서버로 파일이 전송되지 않아 보안이 안전합니다.

간편한 3단계 프로세스

기준 파일 업로드, 취합할 파일 업로드, 취합 및 다운로드의 간단한 과정으로 누구나 쉽게 사용할 수 있습니다.

취합 결과 미리보기

최종 파일을 다운로드하기 전에 어떤 셀의 내용이 어떻게 변경되었는지 색상으로 구분하여 직관적으로 확인할 수 있습니다.

사용 방법

1

Base(기준) 파일 업로드

취합된 데이터가 최종적으로 정리될 '틀'이 되는 엑셀 파일을 업로드합니다.

  • • 화면 왼쪽 상단의 1. Base(Template) 파일 업로드 영역을 클릭하거나 드래그 앤 드롭
  • • 업로드 완료 시 파일명, 크기, 시트 개수 등의 정보 표시
  • • 정상 업로드 시 2단계 영역이 자동으로 활성화
2

담당 부서(취합할) 파일 업로드

기준 파일에 취합할 '내용'이 담긴 엑셀 파일들을 업로드합니다.

  • • 화면 오른쪽 상단의 2. 담당 부서 파일 업로드 영역 클릭 또는 드래그 앤 드롭
  • • 여러 개의 파일을 동시에 선택하여 업로드 가능
  • • 파일 목록과 진행률 표시줄(Progress Bar) 표시
  • • 모든 파일 로드 완료 시 취합 시작 버튼 활성화
3

취합 시작 및 결과 확인

업로드된 파일들을 바탕으로 취합 작업을 실행하고, 그 결과를 미리 확인합니다.

  • • 화면 하단의 취합 시작 버튼 클릭
  • • 취합 결과가 미리보기 형태로 표시
  • • 시트가 여러 개일 경우 상단 시트 탭으로 다른 시트 결과 확인
  • • 하단 통계 정보를 통해 전체 시트 수, 추가/변경된 셀의 개수 확인

미리보기 색상 구분

녹색 셀 기존 Base 파일에서는 비어 있었지만, 부서 파일의 데이터로 새롭게 추가된 값
주황색 셀 기존 Base 파일에도 값이 있었지만, 부서 파일의 값과 달라 새로운 값으로 변경(덮어쓰기)된 값
4

취합된 파일 다운로드

미리보기로 확인한 최종 결과를 하나의 엑셀 파일로 다운로드합니다.

  • • 미리보기 결과 확인 후 파일 다운로드 버튼 클릭
  • • 취합이 완료된 엑셀 파일(시트합_취합결과_날짜.xlsx)이 사용자 PC에 저장
  • • 참고: 다운로드된 최종 파일에는 미리보기의 녹색, 주황색 하이라이트가 포함되지 않음

초기화 기능

모든 작업을 처음부터 다시 시작

언제든지 초기화 버튼을 누르면 업로드된 모든 파일과 작업 내역이 깨끗하게 지워지고 1단계부터 다시 시작할 수 있습니다.

보안 안전: 모든 파일 처리는 사용자 PC에서 직접 이루어집니다.
