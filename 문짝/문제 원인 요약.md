문제 원인 요약:

1. ODT 병합 시 “페이지 나누기”를 잘못 적용함. 코드가 `<text:soft-page-break/>`를 삽입하는데, 이는 보기용 표식이라 강제 페이지 분리가 아니다. 그래서 이전 문서의 부동 개체·프레임이 다음 문서 내용과 겹치며 중간 삽입처럼 보인다.&#x20;
2. 동일한 `xml:id`·`text:name`·`draw:name` 충돌을 처리하지 않음. 북마크, 각주, 리스트, 프레임 등의 식별자가 겹치면 링크·앵커·부동 개체 위치가 앞 문서로 쏠릴 수 있다. 현재 스타일 이름 충돌만 처리한다.&#x20;
3. 그림 외의 임베디드 개체(예: OLE, 차트, Object n/) 경로 재작성과 자산 복사가 불완전. 지금은 `Pictures/`만 복사하고 `draw:image`만 재작성한다.&#x20;

해결 방안(UI/UX 변경 없음. 내부 로직만 패치):

### 1) “진짜” 페이지 나누기 적용

* FO 네임스페이스 추가: `FO: 'urn:oasis:names:tc:opendocument:xmlns:xsl-fo-compatible:1.0'`.
* 자동 스타일에 강제 페이지 분리용 단락 스타일 생성(한 번만):

  * `<style:style style:family="paragraph" style:name="MunjjakPageBreak">`
  * `<style:paragraph-properties fo:break-before="page"/>`
* 구분 시 다음처럼 삽입:

  * `<text:p text:style-name="MunjjakPageBreak"/>`
  * 필요 시 시각적 여백용 `&nbsp;` 단락을 앞뒤로 1개씩.
* 기존 `<text:soft-page-break/>` 사용 부분을 모두 교체. 현재 “페이지 구분” 분기에서 soft-page-break를 넣는다. 여기를 교체한다.&#x20;

### 2) ID·이름 충돌 전면 해소

* 병합 대상 조각(fragment)을 붙이기 **전** 전체 순회하며 다음 속성들을 유니크하게 리네임하고 매핑 테이블 생성:

  * `xml:id`, `text:name`, `draw:name`, `table:name`, `text:id`
* 동일 문서 내부 참조를 갱신:

  * `xlink:href="#..."` 값 치환
  * `*:ref-name`로 끝나는 속성 값 치환(예: `text:ref-name`)
* 이미 구현된 스타일 이름 리라이트(`rewriteStyleRefs`)는 그대로 활용.&#x20;

### 3) 모든 xlink 자산 복사·경로 재작성 일반화

* 두 단계로 처리:

  1. fragment에서 `xlink:href`가 **상대 경로**(예: `Pictures/...`, `Object 1/...`, `media/...`, `Embeddings/...`)인 요소를 모두 수집.
  2. 대상 zip에서 해당 항목을 유니크 파일명으로 복사하고, `manifest.xml`에 file-entry 추가, fragment의 `xlink:href`를 매핑으로 일괄 치환.
* 현재는 그림만(`draw:image`) 처리하므로 `draw:object`, `draw:object-ole` 등도 포함하도록 확장.&#x20;

### 4) 섹션 옵션 보완(선택)

* 이미 “섹션 구분” 옵션 존재. 섹션으로 감싸면 개체 범위가 좁아져 간섭이 줄어든다. 기존 로직은 유지하되(정상), 위 1)\~3)을 기본 적용.&#x20;

## 패치 스니펫(핵심만)

```js
// 0) NS 추가
const ODTNS = {
  OFFICE: 'urn:oasis:names:tc:opendocument:xmlns:office:1.0',
  TEXT: 'urn:oasis:names:tc:opendocument:xmlns:text:1.0',
  DRAW: 'urn:oasis:names:tc:opendocument:xmlns:drawing:1.0',
  XLINK: 'http://www.w3.org/1999/xlink',
  STYLE: 'urn:oasis:names:tc:opendocument:xmlns:style:1.0',
  MANIFEST: 'urn:oasis:names:tc:opendocument:xmlns:manifest:1.0',
  FO: 'urn:oasis:names:tc:opendocument:xmlns:xsl-fo-compatible:1.0'
};

// 1) 강제 페이지 분리 스타일 보장
function ensurePageBreakStyle(doc, autoStyles) {
  const present = Array.from((autoStyles?.children)||[])
    .some(el => el.namespaceURI===ODTNS.STYLE &&
                el.localName==='style' &&
                el.getAttribute('style:name')==='MunjjakPageBreak');
  if (!present) {
    const st = doc.createElementNS(ODTNS.STYLE, 'style:style');
    st.setAttribute('style:family','paragraph');
    st.setAttribute('style:name','MunjjakPageBreak');
    const pp = doc.createElementNS(ODTNS.STYLE, 'style:paragraph-properties');
    pp.setAttributeNS(ODTNS.FO, 'fo:break-before', 'page');
    st.appendChild(pp);
    autoStyles.appendChild(st);
  }
}
function appendHardPageBreak(doc, officeText, autoStyles) {
  ensurePageBreakStyle(doc, autoStyles);
  const spacer1 = doc.createElementNS(ODTNS.TEXT, 'text:p');
  spacer1.appendChild(doc.createTextNode('\u00A0'));
  const br = doc.createElementNS(ODTNS.TEXT, 'text:p');
  br.setAttribute('text:style-name','MunjjakPageBreak');
  const spacer2 = doc.createElementNS(ODTNS.TEXT, 'text:p');
  spacer2.appendChild(doc.createTextNode('\u00A0'));
  officeText.appendChild(spacer1);
  officeText.appendChild(br);
  officeText.appendChild(spacer2);
}

// 2) ID/이름 충돌 해결 + 참조 갱신
function rewriteIdsAndRefs(node, prefix, seen) {
  if (node.nodeType!==1) { for (const c of node.childNodes||[]) rewriteIdsAndRefs(c, prefix, seen); return; }
  const attrs = ['xml:id','text:name','draw:name','table:name','text:id'];
  const refAttrs = ['text:ref-name']; // 값이 이름 자체인 참조
  const hrefNS = ODTNS.XLINK;

  // 수집 및 리네임
  for (const a of attrs) {
    if (node.hasAttribute(a)) {
      const old = node.getAttribute(a);
      let neu = `${prefix}_${old}`;
      while (seen.has(neu)) neu = `${neu}_1`;
      if (old!==neu) {
        seen.set(old, neu);
        node.setAttribute(a, neu);
      } else {
        seen.set(old, neu);
      }
    }
  }

  // 내부 앵커 href 갱신(#id)
  if (node.hasAttributeNS(hrefNS, 'href')) {
    const href = node.getAttributeNS(hrefNS,'href');
    if (href && href.startsWith('#')) {
      const key = href.slice(1);
      if (seen.has(key)) node.setAttributeNS(hrefNS,'xlink:href','#'+seen.get(key));
    }
  }

  // ref-name 갱신
  for (const a of refAttrs) {
    if (node.hasAttribute(a)) {
      const v = node.getAttribute(a);
      if (seen.has(v)) node.setAttribute(a, seen.get(v));
    }
  }

  for (const c of node.childNodes||[]) rewriteIdsAndRefs(c, prefix, seen);
}

// 3) xlink 자산 복사·재작성 일반화
async function copyLinkedAssetsAndRewrite(fdZip, baseZip, docOrFrag, hrefMap) {
  function collectXlinks(root){
    const out=[];
    (function walk(n){
      if (n.nodeType===1) {
        const href = n.getAttributeNS(ODTNS.XLINK,'href');
        if (href && !/^#|^https?:/i.test(href)) out.push(href);
      }
      for (const c of n.childNodes||[]) walk(c);
    })(root);
    return out;
  }
  const paths = collectXlinks(docOrFrag);
  for (const p of paths) {
    const entry = fdZip.files[p] || fdZip.files[p.replace(/^\//,'')];
    if (!entry || entry.dir) continue;
    const newName = uniqueName(p.replace(/^\//,''), n => !!baseZip.files[n]);
    const buf = await entry.async('arraybuffer');
    baseZip.file(newName, buf);
    hrefMap[p] = newName;
    hrefMap['/'+p] = newName;
    await addManifestEntry(baseZip, newName, guessMimeByExt(newName));
  }

  // 모든 xlink:href 일괄 재작성(이미지·OLE·오브젝트 공통)
  (function rewriteHref(n){
    if (n.nodeType!==1) return;
    const href = n.getAttributeNS(ODTNS.XLINK, 'href');
    if (href && hrefMap[href]) n.setAttributeNS(ODTNS.XLINK,'xlink:href', hrefMap[href]);
    for (const c of n.childNodes||[]) rewriteHref(c);
  })(docOrFrag);
}
```

**mergeODTFiles() 수정 포인트(요지만 표시):**

* `option==='pagebreak'` 분기에서 soft-page-break 삽입 부분을 **삭제**하고 `appendHardPageBreak(baseContent, baseOfficeText, baseAutoStyles)` 호출로 교체.&#x20;
* fragment를 붙이기 **직전**에:

  * `const seen = new Map(); rewriteIdsAndRefs(fragment, 'd'+(i+1), seen);`
  * `const hrefMap = {}; await copyLinkedAssetsAndRewrite(fd.zipData, baseZip, fragment, hrefMap);`
* 이후 `baseOfficeText.appendChild(baseContent.importNode(n, true));` 로 기존 부착 유지. 병합 메인 흐름은 동일. 병합 옵션(연속/섹션)은 그대로 유지.&#x20;

## 기대 효과

* 강제 페이지 분리로 문서 경계가 확정되어 중간 삽입처럼 보이는 현상 제거.
* ID/이름 충돌 제거로 앵커·각주·리스트·프레임이 원 소속 문서 범위 안에서만 동작.
* 모든 임베디드 자산 경로를 안전하게 재작성하여 깨진 링크나 잘못된 재배치 방지.

## 간단 테스트 시나리오

1. 이미지와 절대 위치 프레임이 있는 ODT A, 텍스트 많은 ODT B를 “페이지 구분”으로 병합 → B 내용이 A 중간에 끼어들지 않고 새 페이지에서 시작해야 함.
2. 동일한 이름의 북마크·각주가 양 문서에 모두 있을 때 내부 링크·참조가 각 문서 안에서만 동작하는지 확인.
3. OLE 개체 포함 ODT 병합 후 개체가 정상 표시되는지 확인.

필요 시 추가로 `text:sequence-decls` 독립 넘버링까지 분리하도록 확장 가능하나, 위 패치만으로 보고된 “중간 삽입” 증상은 해소된다.&#x20;
