문짝 (Mun-jjak)

문서 작업, 더 이상 복잡하게 하지 마세요!

'문짝'은 여러 개의 문서를 합치고 나누는 복잡한 작업을 클릭 몇 번으로 해결하는 가장 간단하고 안전한 방법입니다.

3

지원 파일 형식

PDF, Excel, TXT

2

핵심 기능

파일 병합 & 분할

1

단 하나의 도구

설치 없이 웹에서 바로

3단계로 끝내는 초간단 문서 관리

파일을 올리고, 작업을 선택하고, 다운로드하면 끝입니다.

1

파일 선택

드래그 앤 드롭 또는 파일 선택 버튼으로 문서를 추가하고 순서를 정렬하세요.

2

작업 선택

병합 또는 분할 작업을 선택하고 파일 유형에 맞는 세부 옵션을 설정하세요.

3

실행 및 다운로드

실행 버튼을 누른 후, 완성된 결과 파일을 즉시 다운로드하세요.

파일 유형별 맞춤 기능

각 문서 형식의 특성에 맞는 강력한 병합/분할 옵션을 제공합니다.

📄 PDF

병합

여러 PDF를 지정한 순서대로 하나의 문서로 합칩니다.

특정 범위 분할

원하는 페이지만 골라 새 PDF로 추출합니다. (예: 1-3, 5)

페이지 단위 분할

지정한 페이지 수만큼 문서를 자동으로 나눕니다.

📊 Excel

병합 옵션

여러 Excel 파일을 시트 분리 또는 시트 통합 방식으로 병합할 수 있습니다.

Sheet/행 단위 분할

각 시트를 개별 파일로 만들거나, 지정한 행 수로 파일을 나눕니다.

📝 텍스트

병합

여러 텍스트 파일을 하나의 파일로 합칩니다.

특정 범위 분할

원하는 라인(줄) 번호만 추출하여 새 파일로 만듭니다.

라인 단위 분할

지정한 라인 수만큼 파일을 자동으로 나눕니다.

'문짝'을 선택해야 하는 이유

💻

설치 불필요

별도의 프로그램 설치 없이 어떤 PC에서든 웹 브라우저로 바로 사용 가능합니다.

🔒

강력한 보안

모든 작업은 사용자 PC에서 직접 처리됩니다. 파일이 외부 서버로 전송되지 않아 안전합니다.

✨

직관적인 사용법

드래그 앤 드롭을 지원하여 누구나 쉽게 파일을 관리하고 작업을 수행할 수 있습니다.

👍

완전 무료

모든 기능은 제한 없이 무료로 제공되어 업무 효율을 높여줍니다.
